## 1. 色彩空间与直方图（S-06、S-07、S-08）

### 1.1 什么时候用哪个空间

| 空间 | 结构 | 工业用途 | 注意 |
|---|---|---|---|
| BGR | 3×uint8 | OpenCV 默认读写 | matplotlib 显示要转 RGB |
| 灰度 | 1×uint8 | 阈值、边缘、模板匹配 | 丢失颜色信息但提速 3 倍 |
| HSV | H(0–179) / S / V | **颜色筛选、色差检测**（`:400`） | H 是环形，红色要处理 0/179 两端 |
| Lab | L / a / b | 与设备无关的色差判断 | a/b 通道可单独做色差阈值 |

### 1.2 直方图能诊断什么

| 直方图形状 | 诊断 | 对策 |
|---|---|---|
| 集中在左侧 | 欠曝 | 伽马 < 1 或加曝光 |
| 集中在右侧且贴 255 | 过曝（信息永久丢失） | 降曝光/缩短曝光时间，**算法救不回来** |
| 明显双峰 | 目标与背景分离好 | Otsu 直接上 |
| 单峰且宽 | 对比度低/光照不均 | 自适应阈值或先打光 |

## 2. 点运算、伽马与 LUT（S-09、S-10、S-18）

### 2.1 三种亮度调整

```python
import cv2
import numpy as np
import time

gray = np.full((1000, 1000), 80, np.uint8)

# ① 线性：g = a*f + b（a 对比度，b 亮度）
linear = cv2.convertScaleAbs(gray, alpha=1.4, beta=30)   # 饱和运算，不会回绕

# ② 伽马：g = 255*(f/255)^gamma，gamma<1 提亮暗部、保住高光
gamma = 0.6
table = np.array([((i / 255.0) ** gamma) * 255
                  for i in range(256)]).astype(np.uint8)
gma = cv2.LUT(gray, table)

# ③ 向量化 vs 逐像素循环（提速三件套之一，原文 :354-357）
t0 = time.perf_counter()
fast = cv2.LUT(gray, table)
t1 = time.perf_counter()
slow = np.zeros_like(gray)
for y in range(0, 200):            # 只跑 200 行做对比，全图会更夸张
    for x in range(0, 1000):
        slow[y, x] = table[gray[y, x]]
t2 = time.perf_counter()
print(f"LUT 全图 {t1 - t0:.4f}s，手写循环仅 1/5 行数 {t2 - t1:.4f}s")
print("结果一致:", np.array_equal(fast[:200], slow))
```

> **结论**：`LUT` / numpy 向量化是 1ms 级，逐像素 Python 循环是 100ms 级。产线 100ms 节拍里，一个循环就能把预算吃光（坑 14 `:776`）。

## 3. 阈值：从"拍脑袋取 128"到 Otsu 原理（S-11、S-12）

### 3.1 四种方式对比

```python
import cv2
import numpy as np

# 合成一张"光照不均 + 深色缺陷"的图，专门用来暴露固定阈值的问题
h, w = 300, 400
yy, xx = np.mgrid[0:h, 0:w]
bg = (150 + 60 * (xx / w)).astype(np.uint8)          # 左边暗、右边亮
img = np.dstack([bg, bg, bg])
cv2.circle(img, (120, 150), 18, (60, 60, 60), -1)     # 暗缺陷 1
cv2.circle(img, (320, 150), 18, (60, 60, 60), -1)     # 暗缺陷 2
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

_, fixed = cv2.threshold(gray, 128, 255, cv2.THRESH_BINARY_INV)
t_otsu, otsu = cv2.threshold(gray, 0, 255,
                             cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)
adap = cv2.adaptiveThreshold(gray, 255,
                             cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                             cv2.THRESH_BINARY_INV, 31, 8)
print("Otsu 自动阈值:", t_otsu)
print("固定阈值白点数:", int((fixed > 0).sum()),
      "Otsu:", int((otsu > 0).sum()),
      "自适应:", int((adap > 0).sum()))
```

**预期现象**：固定 128 会把右侧亮背景整片误判成目标；Otsu 只找一个全局切分点，仍有残留；自适应阈值按邻域局部均值切分，两个缺陷都被干净切出。**这就是"光照不均 → 别用固定阈值"的可复现证据。**

### 3.2 Otsu 原理（面试必答，面试题 17 `:833`）

Otsu 遍历所有候选阈值 `t`，把直方图分成两类，选择使**类间方差**最大的 `t`：

```
w0 = 前景像素数 / 总像素数,  μ0 = 前景均值
w1 = 背景像素数 / 总像素数,  μ1 = 背景均值
σ²_between(t) = w0 · w1 · (μ0 − μ1)²     ← 最大化它
```

手写一个，验证和 OpenCV 结果一致（**能默写这段代码，才算"必须熟"**）：

```python
import cv2
import numpy as np


def otsu_manual(gray):
    """遍历 0–255，最大化类间方差；返回阈值"""
    hist = cv2.calcHist([gray], [0], None, [256], [0, 256]).ravel()
    total = float(gray.size)
    sum_all = float(np.dot(np.arange(256), hist))
    w0, sum0, best_t, best_var = 0.0, 0.0, 0, -1.0
    for t in range(256):
        w0 += hist[t]
        if w0 == 0:
            continue
        w1 = total - w0
        if w1 == 0:
            break
        sum0 += t * hist[t]
        m0, m1 = sum0 / w0, (sum_all - sum0) / w1
        var = w0 * w1 * (m0 - m1) ** 2
        if var > best_var:
            best_var, best_t = var, t
    return best_t


if __name__ == "__main__":
    rng = np.random.default_rng(0)
    g = np.concatenate([rng.normal(60, 12, 4000),
                        rng.normal(190, 15, 6000)]).clip(0, 255).astype(np.uint8)
    t_cv, _ = cv2.threshold(g, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    print("手写:", otsu_manual(g), " OpenCV:", t_cv)   # 双峰图上应当非常接近
```

> **失效场景**：单峰直方图（目标占比 < 1% 的微小缺陷）、光照不均。前者用顶帽/差分，后者用自适应阈值或先解决打光（S-41）。

## 4. 滤波：按噪声选算子（S-13、S-17）

```python
import cv2
import numpy as np

rng = np.random.default_rng(42)
base = np.full((300, 300), 128, np.uint8)
cv2.rectangle(base, (80, 80), (220, 220), 200, -1)
cv2.line(base, (40, 250), (260, 250), 60, 3)

# 椒盐噪声
sp = base.copy()
m = rng.random(base.shape) < 0.03
sp[m] = 0
m2 = rng.random(base.shape) < 0.03
sp[m2] = 255

# 高斯噪声
gn = np.clip(base.astype(np.float32) + rng.normal(0, 22, base.shape),
             0, 255).astype(np.uint8)

gauss = cv2.GaussianBlur(gn, (5, 5), 0)
median = cv2.medianBlur(sp, 5)
bilateral = cv2.bilateralFilter(gn, 9, 75, 75)

for name, out in [("高斯滤波", gauss), ("中值滤波", median), ("双边滤波", bilateral)]:
    src = gn if name != "中值滤波" else sp
    print(f"{name}: PSNR={cv2.PSNR(src, out):.2f} dB")
```

| 噪声 | 首选 | 理由 | 代价 |
|---|---|---|---|
| 椒盐 / 孤立亮点 | `medianBlur` | 取中值直接把孤立极值抹掉 | 核大了会吃掉细线 |
| 高斯 / 传感器噪 | `GaussianBlur` | 加权平均，理论最优 | 边缘被糊 |
| 要保边去噪 | `bilateralFilter` | 空间 + 灰度双重权重 | 慢，别用在 100ms 节拍里 |
| Canny 之前 | `GaussianBlur(5,5)` | 抑制噪声引起的伪边缘（`:185`） | 核太大会丢真实细边 |

> **面试口径**：Canny 第一步就是高斯模糊，因为梯度算子对噪声的一阶导数极其敏感；不模糊会让噪声被当成边缘，双阈值再怎么调都救不回来。

## 5. 形态学：开、闭、顶帽、黑帽（S-14、S-15）

```python
import cv2
import numpy as np

# 合成：亮背景上有暗划痕（细长）+ 亮脏点 + 孤立白噪点
img = np.full((240, 320), 180, np.uint8)
cv2.line(img, (40, 120), (280, 120), 60, 2)      # 暗划痕
cv2.circle(img, (250, 60), 5, 245, -1)           # 亮点
rng = np.random.default_rng(1)
noise = rng.random(img.shape) < 0.01
img[noise] = 255                                  # 白噪点

kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (7, 7))
opened = cv2.morphologyEx(img, cv2.MORPH_OPEN, kernel)     # 去亮噪点
closed = cv2.morphologyEx(img, cv2.MORPH_CLOSE, kernel)    # 填暗小孔
tophat = cv2.morphologyEx(img, cv2.MORPH_TOPHAT, kernel)    # 提"比背景亮"的小目标
blackhat = cv2.morphologyEx(img, cv2.MORPH_BLACKHAT, kernel)  # 提"比背景暗"的小目标

print("顶帽最大响应:", int(tophat.max()), " 黑帽最大响应:", int(blackhat.max()))
```

| 算子 | 公式 | 作用 | 工业场景 |
|---|---|---|---|
| 腐蚀 | 取邻域最小 | 白色区域收缩 | 断开细连接 |
| 膨胀 | 取邻域最大 | 白色区域扩张 | 补断裂 |
| **开** | 先腐后膨 | **去孤立亮噪点**，保整体形状 | 二值图去毛刺（`:340`） |
| **闭** | 先膨后腐 | **连断线、填小孔** | 字符断笔、划痕断续 |
| **顶帽** | 原图 − 开 | 提亮小目标 | 亮脏点、凸起 |
| **黑帽** | 闭 − 原图 | 提暗小目标 | **暗划痕、凹坑**（`:397`） |

> 核形状选择：`MORPH_RECT` 通用，`MORPH_ELLIPSE` 对圆形缺陷更自然，`MORPH_CROSS` 保十字结构。核大小 ≈ 目标短边尺寸，太大把目标也吃掉。

## 6. 综合产出：Trackbar 调参沙盒（P1 雏形，T1-05 – T1-08）

**这是 W2 的交付物，也是后面 46 周最常用的工具**：一张图上同时看 原图 / 二值 / 边缘 / 轮廓，参数实时可调、可存 json、重启复现。

```python
# src/ui/tuner.py —— cv2.Trackbar 版，零额外依赖
import json
from pathlib import Path
import cv2
import numpy as np

CFG = Path("configs/p1.json")
DEFAULT = {"blur": 5, "mode": 1, "thresh": 128, "adapt_c": 8,
           "kernel": 5, "morph": 1, "canny1": 50, "canny2": 150,
           "min_area": 50}


def load_cfg():
    if CFG.exists():
        return json.loads(CFG.read_text(encoding="utf-8"))
    CFG.parent.mkdir(parents=True, exist_ok=True)
    CFG.write_text(json.dumps(DEFAULT, ensure_ascii=False, indent=2), encoding="utf-8")
    return DEFAULT.copy()


def demo_image():
    """没有相机/图片时自动生成一张带渐变、缺陷、噪点的测试图"""
    h, w = 360, 480
    yy, xx = np.mgrid[0:h, 0:w]
    bg = (120 + 70 * (xx / w)).astype(np.uint8)
    img = np.dstack([bg, bg, bg])
    cv2.circle(img, (140, 180), 26, (40, 40, 40), -1)     # 暗缺陷
    cv2.circle(img, (340, 120), 18, (40, 40, 40), -1)
    cv2.rectangle(img, (60, 260), (420, 300), (200, 200, 200), -1)
    rng = np.random.default_rng(3)
    salt = rng.random((h, w)) < 0.006
    img[salt] = 255
    return img


def odd(v, minimum=1):
    v = int(v)
    return max(minimum, v if v % 2 == 1 else v + 1)


def nothing(_):
    pass


def main():
    cfg = load_cfg()
    orig = demo_image()                      # 换成 cv2.imread("data/raw/xxx.png")
    cv2.namedWindow("tuner", cv2.WINDOW_NORMAL)
    keys = ["blur", "mode", "thresh", "adapt_c", "kernel",
            "morph", "canny1", "canny2", "min_area"]
    limits = {"blur": 15, "mode": 2, "thresh": 255, "adapt_c": 20,
              "kernel": 21, "morph": 3, "canny1": 200, "canny2": 300,
              "min_area": 500}
    for k in keys:
        cv2.createTrackbar(k, "tuner", int(cfg[k]), limits[k], nothing)

    print("mode: 0=固定 1=Otsu 2=自适应 | morph: 0=无 1=开 2=闭 3=顶帽")
    print("s=保存参数并退出  q=直接退出")
    while True:
        cur = {k: cv2.getTrackbarPos(k, "tuner") for k in keys}
        gray = cv2.cvtColor(orig, cv2.COLOR_BGR2GRAY)
        blur = cv2.GaussianBlur(gray, (odd(cur["blur"]), odd(cur["blur"])), 0)

        if cur["mode"] == 0:
            _, bw = cv2.threshold(blur, cur["thresh"], 255, cv2.THRESH_BINARY_INV)
        elif cur["mode"] == 1:
            _, bw = cv2.threshold(blur, 0, 255,
                                  cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)
        else:
            bw = cv2.adaptiveThreshold(
                blur, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                cv2.THRESH_BINARY_INV, 31, max(1, cur["adapt_c"]))

        k = cv2.getStructuringElement(cv2.MORPH_ELLIPSE,
                                      (odd(cur["kernel"]), odd(cur["kernel"])))
        morph_id = [None, cv2.MORPH_OPEN, cv2.MORPH_CLOSE,
                    cv2.MORPH_TOPHAT][cur["morph"]]
        bw = cv2.morphologyEx(bw, morph_id, k) if morph_id is not None else bw

        edges = cv2.Canny(blur, cur["canny1"], max(cur["canny1"] + 1, cur["canny2"]))
        overlay = orig.copy()
        cnts = cv2.findContours(bw, cv2.RETR_EXTERNAL,
                                cv2.CHAIN_APPROX_SIMPLE)[-2]
        kept = 0
        for c in cnts:
            area = cv2.contourArea(c)
            if area >= cur["min_area"]:
                x, y, w, h = cv2.boundingRect(c)
                cv2.rectangle(overlay, (x, y), (x + w, y + h), (0, 0, 255), 2)
                cv2.putText(overlay, f"{int(area)}", (x, y - 4),
                            cv2.FONT_HERSHEY_SIMPLEX, 0.45, (0, 255, 0), 1)
                kept += 1

        def to_bgr(a):
            return cv2.cvtColor(a, cv2.COLOR_GRAY2BGR) if a.ndim == 2 else a

        def label(a, text):
            out = to_bgr(a).copy()
            cv2.putText(out, text, (6, 20), cv2.FONT_HERSHEY_SIMPLEX,
                        0.55, (0, 255, 0), 1, cv2.LINE_AA)
            return out

        top = np.hstack([label(orig, "origin"), label(bw, "binary")])
        bottom = np.hstack([label(edges, "edges"),
                            label(overlay, f"contours={kept}")])
        cv2.imshow("tuner", np.vstack([top, bottom]))

        key = cv2.waitKey(30) & 0xFF
        if key == ord("s"):
            CFG.write_text(json.dumps(cur, ensure_ascii=False, indent=2),
                           encoding="utf-8")
            print("参数已保存:", CFG, cur)
            break
        if key == ord("q"):
            break
    cv2.destroyAllWindows()


if __name__ == "__main__":
    main()
```

**P1 升级到 PySide6 的骨架**（W4 前完成，原文 `:513`）：把 `cv2.imshow` 换成 `QLabel` + `QImage`，滑块换成 `QSlider`，`waitKey` 换成 `QTimer` 定时 30ms 刷新；核心算法函数 `process(orig, cfg) -> (binary, edges, overlay)` **保持纯函数、不依赖 UI**，这样后面 P6 直接复用。

```python
# src/algo/pipeline.py —— 与界面解耦的纯算法层（P6 架构的第一块砖）
import cv2


def process(bgr, cfg):
    gray = cv2.cvtColor(bgr, cv2.COLOR_BGR2GRAY)
    k = cfg.get("blur", 5) | 1
    blur = cv2.GaussianBlur(gray, (k, k), 0)
    if cfg.get("use_otsu", True):
        _, bw = cv2.threshold(blur, 0, 255,
                              cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)
    else:
        _, bw = cv2.threshold(blur, cfg["thresh"], 255, cv2.THRESH_BINARY_INV)
    edges = cv2.Canny(blur, cfg.get("canny1", 50), cfg.get("canny2", 150))
    return {"gray": gray, "binary": bw, "edges": edges}
```
