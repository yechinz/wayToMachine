## 5. 环境说明（结合你当前机器，避免第一周就卡住）

路线图 `:130-139` 给的是标准装法；**你实际环境是 Windows + conda `industrial_vision`（Python 3.11、OpenCV 5.x、无 GPU）**，因此：

| 项 | 路线图建议 | 你的落地调整 |
|---|---|---|
| Python | 3.10 / 3.11 | 沿用 3.11，符合建议 |
| OpenCV | `opencv-contrib-python==4.10.*` | 若已装 5.x 不必降级，但**注意 3.x/4.x/5.x 的返回值差异**（如 `findContours`），手册代码统一写兼容写法 `cnt[-2]` |
| numpy | 锁 1.26 | 若 5.x 依赖 numpy 2.x，不要强降；以 `import cv2, numpy` 不报错为准 |
| 深度学习 | YOLO / anomalib / TensorRT | **无 GPU**：训练走 CPU 小数据集 / 云端 Notebook；推理走 ONNX Runtime CPU + OpenVINO；TensorRT 只需了解链路 |
| 相机 | 工业相机 SDK | 没有相机时全部示例用 `numpy` 合成图，先跑通算法；W9 再上硬件 |

**环境自检脚本（Day1 第一条命令）：**

```python
# check_env.py：把输出截图存到 docs/env_check.png 或贴进 docs/env.md
import sys, cv2, numpy as np
print("Python     :", sys.version.split()[0])
print("OpenCV     :", cv2.__version__)
print("NumPy      :", np.__version__)
print("SIFT 可用  :", hasattr(cv2, "SIFT_create"))       # 需要 opencv-contrib
print("线程数     :", cv2.getNumThreads())

# 合成一张图，验证 imread/imwrite/像素运算链路
img = np.zeros((120, 200, 3), np.uint8)
cv2.circle(img, (100, 60), 40, (0, 255, 0), -1)
cv2.imwrite("docs/env_check.png", img)
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
print("灰度均值   :", round(float(gray.mean()), 2))
```

> ⚠️ 路线图 `:143`：`opencv-python` 与 `opencv-contrib-python` **只能装一个**，contrib 是超集（含 SIFT、ArUco）。若 `SIFT_create` 不可用，说明装的是主包，卸载后重装 contrib，不要在两个包共存的环境里调 bug。

**参数外置最小示例**（从第 1 周就养成，对应 `S-58` 配置化）：

```python
# src/algo/threshold_cfg.py：参数与算法分离的典型写法
import json
from pathlib import Path

DEFAULT = {"blur_ksize": 5, "thresh": 0, "use_otsu": True, "min_area": 50}

def load_cfg(path="configs/p1.json"):
    p = Path(path)
    if not p.exists():
        p.parent.mkdir(parents=True, exist_ok=True)
        p.write_text(json.dumps(DEFAULT, ensure_ascii=False, indent=2), encoding="utf-8")
        return DEFAULT.copy()
    return json.loads(p.read_text(encoding="utf-8"))

def save_cfg(cfg, path="configs/p1.json"):
    Path(path).write_text(json.dumps(cfg, ensure_ascii=False, indent=2), encoding="utf-8")

if __name__ == "__main__":
    cfg = load_cfg()
    cfg["min_area"] = 80
    save_cfg(cfg)
    print("当前参数:", load_cfg())
```

## 7. 学习效率机制（这四件事比"多看两小时视频"管用）

### 7.1 破坏性实验（每章必做，来自 `:188`、`:908`）

每学一个算子，做三次修改并记录现象：

| 修改 | 观察什么 | 记录到 |
|---|---|---|
| 参数加倍 / 减半 | 结果何时开始变坏 | `docs/params.md` |
| 换一张自己拍的图（反光/模糊/倾斜） | 哪个假设失效 | `docs/failures.md` |
| 故意去掉一步预处理 | 能否解释为什么失败 | 手册自测题 |

### 7.2 回归图库（对应 `S-60` 回归测试，原文 `:498`）

`data/regression/` 至少放 10 张图：清晰/模糊/过曝/欠曝/反光/倾斜/遮挡/脏污/同类不同件/NG 件。
每次改算法执行一句约定：`python tests/run_regression.py`，对比前后漏检数。

### 7.3 费曼输出 + 公开承诺（原文 `:1016`）

每 4 周写 1 篇技术博客（W8、W20、W32、W48），模板在 `01` 号文件第 7 节。
讲不清的概念回查 `02` 号文件的自测题，直到能口述 3 分钟。

### 7.4 间隔复习表（防止"学完 W3 忘 W1"）

| 复习点 | 时点 | 动作 |
|---|---|---|
| R1 | 学后第 1 天 | 不看笔记，默写核心 API 链路 |
| R3 | 第 3 天 | 重跑一次代码，改一个参数 |
