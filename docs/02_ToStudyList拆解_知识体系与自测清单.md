## 0. 先弄懂这份文件是什么

> **一句话：这是一份「查 + 打分」用的索引，不是从头读到尾的课本。**
> 之前读不懂，多半是因为拿它当教材顺着读 —— 就像没人会把字典从第 1 页读到最后一页。

### 0.1 ToStudyList 到底是什么

路线图原文里**没有** `todolist` / `tostudylist` 这两个标题，是 `00` 号文件 §1 把路线图拆成了两半：

| | ToDoList（做） | ToStudyList（懂） |
|---|---|---|
| 在哪个文件 | `01` 号，编号 `T0-01` … `T4-20` | **本文件 `02`**，编号 `S-01` … `S-60` |
| 问的是 | 「这周要交出什么东西？」 | 「这个道理我能不能讲清楚？」 |
| 产出形式 | 代码、图片、报告、可运行程序 | 一个能口述的答案（原理 / 公式 / 取舍 / 误差来源） |
| 举 W2 的例子 | 写出固定阈值 / Otsu / 自适应阈值三路切换的 `threshold.py` | 能解释「Otsu 为什么在双峰直方图上有效、单峰为什么失效」 |
| 验收方式 | 跑一遍，看输出对不对 | 不看笔记，口头答一遍右侧的自测题 |

**两者靠编号互相索引**：`01` 的任务行末写 `（S-11 S-15）`＝做这个任务要用到哪几个知识点；本文件的「关联任务」列写 `T1-05`＝这个知识点在哪个任务里练。

### 0.2 想干什么 → 打开哪个文件

| 我现在想… | 打开 | 别打开本文件的原因 |
|---|---|---|
| 知道这周该写什么代码 | `01` | 本文件不写操作步骤 |
| 学某个原理、看代码、做实验 | `03`–`09` 对应阶段手册 | 本文件只有一行知识点 + 一道题，没有讲解 |
| 忘了 API 参数 / 面试前突击 | `10` 速查手册 | 本文件不是速查表 |
| **检查自己有没有真学会 / 季度打分** | **本文件 `02`** | ← 这才是它的唯一用途 |
| 卡住了，不知道该先补哪个知识点 | 本文件 §11 前置依赖表 | — |

### 0.3 三种正确打开方式

| 场景 | 翻到 | 做什么 |
|---|---|---|
| 每周学完（最常用） | 该周对应的那一节（§4–§10） | 逐行口头答自测题，答不出的在编号前标 `?`，按 §2 的三步法补 |

### 0.4 今天打开后的第一件事（照做 3 步）

1. 翻到 **§4**（S-01 – S-05，只有 5 行），**只看这 5 行**，别往下翻。
2. 遮住左边，逐行口头回答最右列的「自测题」，答不出的在编号前标 `?`。
3. 给这 5 行各打一个 0–5 分，填进 §14 的表。

## 2. 怎么算「会了」

### 2.1 自评分标准（每季度重打一次）

| 分 | 标准 | 一句话判断 |
|---|---|---|
| 0 | 没听过 | — |
| 1 | 听懂了，但说不出关键点 | 只能点头 |
| 2 | 能照着代码跑通 | 离不开样例 |
| 3 | 能独立写出来，但解释不清参数 | 会写不会讲 |
| 4 | 能解释原理 + 说清失败场景 | **合格线** |
| 5 | 能讲给别人、能答面试追问、能定位现场问题 | 可以上岗 |

**规则：`P0` 项 < 4 分不得进入下一阶段**（对应 `01` 号文件各阶段验收）；任何 P0 ≤ 3 分，下季度前 2 周优先补它。

### 2.2 答不上自测题时，按这三步走（不要只是重读文字）

1. **查讲解**：按 §2.3 的「答案索引」打开对应阶段手册的具体章节，读原理 + 跑一遍代码。
2. **做破坏性实验**：故意改一个参数 / 换一张自己拍的图 / 去掉一步预处理，把现象写进 `docs/failures.md`。路线图 `:188` 的原话是「抄通不算会」。
3. **再答一遍**：合上笔记口头答，答到 §1.2 里该掌握度的过关标准为止。
